# MOKO_ExPlugin

Проект на LabVIEW для создания и управления внешними плагинами для MOKO SE.

## Описание

Этот проект представляет собой фреймворк или шаблон для разработки плагинов, расширяющих функциональность основной программы MOKO SE. Файл `steps develop plugin.txt` описывает шаги, необходимые для создания нового плагина, что подтверждает назначение проекта.

Плагины, созданные с помощью этого фреймворка, по-видимому, используют клиент-серверную архитектуру с несколькими циклами (сервер, события, основной) и state-machine (STM) для управления логикой.

## Структура проекта

- **MOKO ExPlugin.lvproj**: Основной файл проекта LabVIEW.
- **MOKO ExPlugin.vi**: Главный VI, вероятно, шаблон или пример плагина.
- **steps develop plugin.txt**: Инструкция по разработке нового плагина.
- **Lib/**, **Pictures/**, **Icon/**: Библиотеки, изображения и иконки для использования в плагинах.
- **App/**: Скомпилированная версия плагина.
- **iss/**: Скрипт для создания инсталлятора с помощью Inno Setup.

## Ключевые технологии

- LabVIEW
- Веб-сервисы LabVIEW
- Inno Setup
